# Cloud Separation by Height

**Author:** Justin Scholz — [jscholz@bcf-engr.com](mailto:jscholz@bcf-engr.com)
**Date:** June 11, 2026

Separates point cloud by height position.  Usefull when removing data above or below a known elevation.  This script will create a new limit box, to see your data delete the box after the script has run.
