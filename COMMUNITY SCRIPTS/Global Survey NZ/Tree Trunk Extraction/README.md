# Tree Trunk Extraction

Automates the extraction of tree trunks from point clouds in Leica Cyclone 3DR.

## Description

This script automates the process of extracting tree trunks from a classified point cloud. It uses the point cloud classifications (such as vegetation and ground) to intelligently isolate and model tree trunks. 

It features two distinct workflows:
- **Loopable Preview Mode:** Generates 3D Cylinders hovering exactly over the trunks for rapid visual inspection and quality control.
- **Final Export Mode:** Projects the 3D axes mathematically onto the DTM (Digital Terrain Model) topographical ground to generate 2D CAD Topo Rings, ready for survey drafting!

## Tested version
